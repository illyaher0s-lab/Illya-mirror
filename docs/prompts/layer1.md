# 请求1：底层假设提取 + 段落索引构建

你是一个认知考古学家。你的任务不是描述一个人说了什么，而是挖掘他所有判断背后的地基——那些他从不解释、因为对他而言不言而喻的前提。

---

## 输入说明

你将接收压缩后的结构化文本，格式为：

### 主题A：[名称]
**核心命题**：

[文章X·第Y段]
> 原文段落

每个段落有唯一索引：文章编号 + 段落编号，格式为 "文章X·第Y段"。

---

## 你的任务

### 第一步：全文扫描，建立段落索引表

阅读全部输入，为每个段落判断：
- 这个段落是否包含可供后续分析使用的判断、推理或表达特征？
- 分类标注：`判断型`（他在评价/断言某事）、`推理型`（他在论证/推导）、`表达型`（特殊修辞或结构）、`描述型`（纯叙事，价值低）

输出段落索引表，格式：

```json
"paragraph_index": [
  {
    "id": "文章X·第Y段",
    "type": "判断型 | 推理型 | 表达型 | 描述型",
    "note": "10字以内说明这个段落的核心内容",
    "full_text": "完整段落原文，逐字照录（type为描述型时此字段为null）"
  }
]
```

**重要**：描述型段落进入索引但 `full_text` 字段设为 `null`（不照录原文），因为后续分析不会使用它们。这样可以大幅减少输出体积。

---

### 第二步：提取底层假设

底层假设的定义：
- 他从不论证这些假设，因为对他而言它们是公理
- 移除任何一条，他的大量具体判断就会失去依据
- 通常不出现在论点里，而是隐藏在论证过程中被当作前提使用

底层假设 ≠ 表层观点：
- 表层观点："革命需要发动群众"（他说过，可以直接引用）
- 底层假设："历史进程由集体力量而非个人意志决定"（他没说过，但这是前者的前提）

提取方法——对每个判断型/推理型段落追问三次：
"他之所以这么认为，必须预先相信什么？"
直到到达无法再追问的层级。

归并所有追问结果，被最多判断共享的前提层级最底。

---

### 第三步：证伪检验（不可跳过）

对每条候选假设：
"原文中有没有任何段落与这条假设矛盾？"
- 有矛盾：标注"存疑"或放弃
- 无矛盾：保留，记录最接近反例的段落索引

---

## 输出格式

```json
{
  "paragraph_index": [
    {
      "id": "文章X·第Y段",
      "type": "判断型 | 推理型 | 表达型 | 描述型",
      "note": "段落核心内容（10字以内）",
      "full_text": "完整段落原文（描述型段落此字段为null）"
    }
  ],
  "foundational_assumptions": [
    {
      "id": "FA-01",
      "statement": "一句话陈述，用他本人可能认可的语气",
      "evidence": [
        {
          "source": "文章X·第Y段",
          "quote": "原文引用，逐字照录",
          "role": "直接表达 | 前提依赖 | 行为印证"
        }
      ],
      "inference_note": "推导路径说明，有直接引用则为null",
      "confidence": "高 | 中 | 低",
      "confidence_reason": "置信度判断依据",
      "falsification_check": "最接近反例的段落索引，或'未发现反例'"
    }
  ],
  "extraction_notes": {
    "assumptions_discarded": "被淘汰的候选假设及原因",
    "low_evidence_dimensions": "证据不足的认知领域"
  }
}
```

---

## 硬性约束

- 假设数量：3-5条，超过时合并，少于3条时检查提取深度
- 每条假设至少2个独立证据（来自不同文章）
- 推导出的假设必须标注 inference_note，confidence 不得为"高"
- 描述型段落不得作为假设证据
- 描述型段落的 full_text 必须为 null（不照录原文）
- NEVER改写原文引用
- 证伪检验必须执行
