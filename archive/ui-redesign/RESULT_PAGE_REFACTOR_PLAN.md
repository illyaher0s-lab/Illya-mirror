# 结果页重构计划

## 问题诊断

### 1. 层级切换显示异常（第三层变空白）
**根本原因**：代码逻辑正常，但可能是：
- 数据结构问题：`taskData.layer3_result` 为空或格式不符
- 渲染条件判断：`renderLayer3Content()` 返回"暂无数据"但样式不明显
- CSS 问题：文字颜色与背景色冲突

**修复方案**：
- 统一空状态样式：明确的卡片 + 图标 + 提示文字 + 操作按钮
- 添加调试信息：在开发模式下显示数据结构
- 改进条件判断：检查 `data.expression_strategies` 和 `data.signature_phrases` 是否都为空

### 2. "质量报告"看起来像文字，不像按钮
**根本原因**：
- 当前实现：`activeTab` 切换（"蒸馏内容" vs "质量报告"）
- 视觉问题：按钮样式不够明显，hover 状态不清晰

**修复方案**：
- 统一按钮样式：与层级切换按钮保持一致
- 增强 hover/active 状态：明确的背景色变化
- 添加图标：📄 蒸馏内容 | 📊 质量报告

### 3. 页面留白过大，内容分散
**根本原因**：
- 当前 `max-w-6xl`（1152px）过宽
- 内容区没有统一容器，各部分独立

**修复方案**：
- 改为 `max-w-5xl`（1024px）
- 减少垂直间距：`py-12` → `py-8`
- 统一内容容器：所有内容放在同一个卡片内

### 4. 字体大小不统一
**当前字号混乱**：
- 标题：`text-5xl`（48px）、`text-2xl`（24px）、`text-xl`（20px）、`text-lg`（18px）
- 正文：`text-sm`（14px）、`text-xs`（12px）
- 按钮：`text-sm`（14px）

**修复方案**：
- H1（页面标题）：`text-4xl`（36px）
- H2（区块标题）：`text-2xl`（24px）
- H3（小标题）：`text-lg`（18px）
- 正文：`text-base`（16px）
- 辅助文字：`text-sm`（14px）
- 按钮：`text-base`（16px）

### 5. 缺少交互状态
**当前问题**：
- 层级切换按钮：有 hover 但不明显
- Tab 按钮：有 hover 但不明显
- 导出按钮：有 disabled 状态但没有 hover

**修复方案**：
- 统一 hover 状态：`hover:opacity-90 transition-all duration-200`
- 统一 active 状态：`active:scale-95`
- 统一 disabled 状态：`disabled:opacity-50 disabled:cursor-not-allowed`

### 6. 缺少空状态、加载状态、错误状态
**当前问题**：
- 第三层没数据时只显示"暂无数据"（灰色小字，不明显）
- 没有"返回其他层级"的入口

**修复方案**：
- 空状态卡片：大图标 + 提示文字 + 操作按钮（"查看其他层级" / "返回首页"）
- 统一空状态样式：`kenya-card` + `text-center` + `py-20`

- 统一样式：与层级切换按钮一致

- 层级切换 + Tab 切换 + 内容展示 + 底部操作
