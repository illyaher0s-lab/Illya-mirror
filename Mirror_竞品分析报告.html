项目介绍（30 秒版本）

Mirror 是一个多阶段 LLM 蒸馏系统，用 Gemini 2.0 Flash 压缩长文本，再用 Claude Sonnet 4 进行四层串行蒸馏，最终生成认知画像。我调研了 GitHub 上 5 个同类项目，发现只有 Mirror 实现了多层蒸馏和认知画像生成，这是我的差异化优势。技术栈是 FastAPI + React + PostgreSQL，已部署到腾讯云，支持实时进度监控和质量评估。

技术亮点（回答"你做了什么"）

1. 双模型架构 — 用 Gemini 做压缩（便宜快），用 Claude 做蒸馏（质量高），单任务成本控制在 $0.20 以内
2. 四层串行蒸馏 — Layer 1 提取段落索引，Layer 2/3 只传索引不传原文，节省 60% tokens
3. 质量评估系统 — 置信度评分 + Bad Case 检测 + 覆盖度分析，确保输出质量
4. 后台线程处理 — 用 Python threading 实现异步任务，前端轮询获取进度

竞品对比（回答"为什么不用现成的"）

我调研了 neo4j-labs 的 llm-graph-builder（4.6k stars）和其他 4 个项目，发现它们都是单层知识提取，输出知识图谱。Mirror 的定位不同：我做的是多层蒸馏，从底层假设到认知画像，逐层提炼，最终输出的是作者的思维模式，而不是知识点。这个方向在 GitHub 上没有竞品，是我的独家特性。
